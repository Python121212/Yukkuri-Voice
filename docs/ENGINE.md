# エンジン設計メモ

## 目標
「ゆっくり声」の特徴を、パラメータとして明示的に再現すること。

ゆっくり声の印象は主に次の 3 つで決まる。

1. **高い F0 と平坦なピッチ** — 抑揚を小さく、文末だけ軽く下げる
2. **フォルマントの上方シフト** — 声道長が短い話者に相当（倍率 1.05〜1.16）
3. **遅い話速と長い母音** — 0.55〜0.9 倍速、母音 95〜115ms

これらは `YkPreset` のフィールドとして外部化してあり、
キャラクタはプリセットの組み合わせで表現する。

## 音源モデル
      声帯パルス ──┐
                    ├─→ 5 段共振器 (F1..F5) ─→ 放射特性 ─→ 自動音量 ─→ 出力
      帯域ノイズ ──┘

- **声帯パルス**: ノコギリ波 + 3 次歪み（`saw - 0.4 saw^3`）を 1.4kHz でローパス。
  F0 には 5.4Hz のビブラートと微小ジッタを重ねる。
- **帯域ノイズ**: 摩擦音の帯域（`/s/` 6.2kHz、`/sh/` 3.4kHz、`/h/` 1.6kHz）を
  2 次共振器で作る。破裂音は閉鎖（無音）＋バースト。
- **共振器**: `H(z) = a / (1 - b z^-1 - c z^-2)`、`a = 1 - b - c` で DC ゲイン 1。
  帯域幅は F1 で最も狭く、高次ほど広い（`mult = {1.0, 1.15, 1.9, 2.6, 3.4}`）。
  F1/F2 は Q の上限を設けて低い F0 での発振を防ぐ。
- **帯域幅の下限と F0**: 高調波は F0 間隔（この声で 260–280Hz）で並ぶので、
  帯域幅が狭すぎると倍音が山を飛び越えて山谷が深くなり「スカスカ」して聞こえ、
  広すぎると隣のフォルマントとつながって母音の輪郭がぼやける
  （「うー…」「いー…」と伸びた印象）。
  下限を `0.75*F0` にして両者のバランスを取っている。
  以前は `1.15*F0` だったため全次が 270Hz に張り付き、`mult` の設計が
  効いていなかった（実測の比較表は `bw_for()` のコメントを参照）。
- **放射特性**: 唇の放射は +6dB/oct。サンプル差分で近似するが、
  共振器のピーク付近で暴れないよう係数 0.7 の弱い傾斜にしている。
- **音量**: 音素ごとの `gain`（母音の共振器減衰差を吸収）と、
  短時間 RMS の 75 パーセンタイルを基準にした全体正規化の 2 段構え。

## 音素表
`core/src/phones.c` の `YkPhoneInfo` がすべて。

| フィールド | 意味 |
|---|---|
| `voiced` / `formant[5]` / `bw` | 有声源とその共鳴特性 |
| `noise` / `noiseHp` / `noiseF` / `noiseBw` | 摩擦・破裂ノイズ |
| `amp` / `gain` | 振幅と共振器減衰の補正 |
| `dur` | 既定長 [ms] |

母音は `core/src/internal.h` の `YK_VOWEL_F`（成人男性の平均値）を使い、
`formantScale` を掛けて声質を作る。

### 表の行数は `YK_P_COUNT` と一致させること

`T[YK_P_COUNT]` は指定子つきで初期化してあるので、**行が足りないと
コンパイラは何も言わずに残りを 0 埋めする**（余剰なら警告が出るが、
不足は出ない）。行が 1 つ抜けただけで、それ以降の音素がすべて 1 つ
ずつ後ろの行で合成される。

実際に「ʔ」（声門破裂）の行が抜けていたため、`YK_P_GLOTTAL` は
1 つ後ろの「つ」（= /ts/, `noise 1.10`）の行で合成され、「あいうえお」の
母音と母音のあいだに 75ms の破擦音が鳴り、**「あじずぜぞ」に聞こえていた**。
`test_phone_table_matches_enum` が記号の空欄と `YK_P_GLOTTAL` の
`noise` / `dur` を見張る。

## 母音の連続（「あいうえお」）

母音が続くところには**何も挟まない**。日本語の「あいうえお」は母音が
続くだけで、声門を閉じる必要はない。

以前は `plan.c` が母音のあいだに `YK_P_GLOTTAL` を挟んでいた。これが
上のテーブルずれと重なって破擦音になっていたうえ、声門破裂そのものも
直後の母音を 4ms のコサイン窓で 0 から立ち上げるため、境界ごとに
幅広いクリック（実測 HF −35dB）を作っていた。母音をそのままつなげると、
境界はフォルマントの補間だけで滑らかにつながる。

| 「あいうえお」 | 修正前 | 修正後 |
|---|---|---|
| 8kHz 以上のエネルギー比（最大） | −15.0 dB | **−73.9 dB** |
| 2–8kHz のエネルギー比（最大） | −0.1 dB | **−6.0 dB** |
| モーラ間の最小 RMS | 0.018 | 0.021（無音なし） |

声門破裂は音素記号 `?` で明示したときだけ使う
（`ykcli "a ? i" out.wav yukkuri --symbols`）。この経路は
`noise 0` / `dur 20ms` で、前後の母音のフォルマントを補間するだけの
短い橋渡しになる（8kHz 以上の比 −33dB、無音の分断なし）。

## 韻律
`symbols.c` の `yk_apply_accent()`。かな入力と記号入力の両方が通る。

- **アクセント句**ごとに、モーラ位置 (`mora` / `moras`) と
  アクセント核 (`accent`) を求める
- 平板 (核なし) は「1 拍目が低く、2 拍目から高いまま下がらない」
- 頭高 (核 = 0) は「1 拍目が高く、すぐ下がる」
- 中高・尾高 (核 = N) は「1 拍目が低く、N 拍目まで高く、そのあと下がる」
- 高い段 = プリセットのピッチ、低い段 = −2.2 半音。高い段を基準に置くのは、
  平板が最も多い日本語では「耳に届く高さ = 高い段」になるため。声質
  (= プリセットのピッチ) を変えずにアクセントだけを付けられる
- 句末の 1 拍だけ下げる (declination)。全拍に掛けると句全体が沈む
- `intonation` プリセット値でこの抑揚の深さを調整
- `intonation` プリセット値でこの抑揚の深さを調整
- 文末の母音は F1 を `3*f0` 以下に抑える。文末で F0 が 280→245Hz まで下がると、
  /e/ の F1=500Hz では 2 次倍音が山の中心から外れて母音の芯が失われるため。

## モーラの長さ

- 話速 `speed = 0.80`（「ゆっくり」のための意図的な減速）
- 母音は合成時に **1.45 倍** へ伸ばす（短すぎると共鳴が立ち上がる前に
  次の子音が来て「プ」のようにこもるため）
- 結果、CV モーラは約 280ms、うち母音が約 200ms（71%）
- **出力サンプル数の見積もりでもこの 1.45 倍を数える必要がある。**
  数え落とすと実測ループが上限に達して末尾の母音が切り捨てられる
  （句点で終わる文で約 100ms 短くなっていた）。
- 文末の休止は 120ms に詰める（長い無音は「もう終わった」印象になる）

記号列で `'` を指定した句はその位置をアクセント核として尊重する。
指定の無い句は、句の長さから「平板 / 中高」を推定する
(4 モーラ以上は中高、それ未満は平板)。将来はアクセント辞書
(例: 東京式アクセント) に差し替える想定で、`yk_apply_accent()` の
核を決める部分だけを交換すればよい構造にしてある。

### 以前との違い (なぜ直したか)

以前は「2 モーラ周期の強弱」を `amp` (音量) に掛けるだけで、**F0 には
一切触れていなかった**。そのため同じ音素列の「はし (端)」「箸」「橋」が
すべて 280Hz の平板で、区別できなかった。いまはアクセントをピッチで表す。

## 揺らぎ（機械っぽさを消す）

同じ入力からは必ず同じ波形が出る（`test_deterministic`）が、決定的であることと
「全部の音節が同じ形」であることは別問題で、後者は強い機械っぽさになる。
以前は次の 4 点で完全に揃っていた。

| 箇所 | 以前 | 現在 |
|---|---|---|
| ビブラート | 5.2Hz・固定振幅を最初から最後まで | 母音の 35% 以降で深さ 0→1 に立ち上がる。開始位相も母音ごとにずらす |
| ジッタ | 実効 0.03 半音（ほぼゼロ） | 15ms 平滑の揺らぎ + 数 Hz のゆっくりしたうねりの 2 成分 |
| シマー | なし（周期ごとの振幅が一定） | 周期の数倍の速さで ±6% |
| 立ち上がり・調音 | 全音節が同じ 3ms、同じフォルマント | 立ち上がり ±30%、F1–F5 を ±2.5%、帯域幅を ±10% |

乱数はすべて決定論的な Xorshift から作るので、再現性（同じ入力なら同じ波形）は保たれる。
**フォルマントを揺らすときは ±2.5% までにする。** これを超えると母音の
弁別（特に /う/ と /え/）が落ちる。実測で最接近母音対の距離は 0.352 → 0.357 と
むしろ微増で、弁別は保たれている。

### 揺らぎの測り方

| 指標 | 修正前 | 修正後 |
|---|---|---|
| 周期ジッタ（局所、%） | 0.51 | 0.86 |
| ビブラート深さ（F0 の速い成分 rms） | 3.43Hz | 1.58Hz |
| 倍音間の谷（小さいほど濁らない） | −7.0dB | −8.4dB |

ビブラートが浅くなったのは、常時掛けていたぶんが無くなったため。
倍音間の谷が下がっているので、揺らぎを足しても「ザラザラ」した雑音は増えていない。
子音の重心（さ/す 4748Hz、し 3842→3992Hz、は 3311Hz）と母音の rms は据え置き。


## 広帯域ノイズ（「ザー」というザラつき）

子音・閉鎖・気息に平坦な白色雑音が乗り、音節の頭と間に
「ザー」という耳障りな帯域が出ていた。原因は 3 経路:

| 経路 | 何が問題だったか | 修正 |
|---|---|---|
| 閉鎖中の息の床 | 1 極 LP だけで丸めており、−3dB が **4.1kHz** のほぼ広帯域ノイズ | 2 極 LP (−3dB ≈ 420Hz) にして低域だけ残す |
| 摩擦/気息の `nzLow` | `nz - LP(nz)` は 2.5kHz 以上の**ハイパス**で、これを 0.12 倍で直接混ぜていた | 撤去。ノイズ全体を 2 極 LP 8kHz で頭打ちに |
| 破裂のバースト | `burst - burstHp` を先に絞らずに差し引いていたため、ナイキスト近くまで成分が残る | 生ノイズを先に 2 極 LP 2.5kHz に絞ってから差し引く |

**8kHz 以上のエネルギー比** (20ms 窓の最大値、小さいほど良い):

| 箇所 | 修正前 | 修正後 |
|---|---|---|
| 閉鎖 (っ) | −9.4 dB | −45.0 dB |
| 破裂 (か) | −20.5 dB | −27.4 dB |
| 気息 (か) | −11.4 dB | −23.8 dB |
| 摩擦 (し) | −14.4 dB | −20.9 dB |
| 母音 (う) | −82 dB | −82 dB |

破裂の重心は か 3632→3322Hz、た 3887→3719Hz とほぼ据え置き
(「カ」「タ」らしさは保つ)。摩擦音の重心も さ/す 4660Hz、し 3834Hz で不変。
`test_no_broadband_hiss` が回帰を防ぐ (−16dB を超えたら失敗)。


## 子音が「ざ」に化ける（ノイズ経路の正規化）

「か・さ・た・な・は・ま・や・ら・わ」のどれも「ざ」に聞こえる、という
報告。原因はノイズ経路のミックスゲインの決め方だった。

摩擦音・破裂の気息は `noiseBuf` に貯めておき、あとから有声出力に足す。
このとき「ノイズの最大値が有声の最大値より -12dB になる」ように
正規化する。以前はこれを**語全体で 1 つのゲイン**として計算していた。

```
g = sqrt(peakV / peakN) * 0.25     ← 語全体の最強窓で 1 回だけ
```

これが 2 つの形で壊れていた。

1. **摩擦音を含まない語** (「な」「ま」「か」単独) では、分母 `peakN` が
   鼻音・気息のごく小さなノイズになる。実測で `な` のゲインは **32 倍**
   (`か` は 0.83 倍)。鼻音の息が 39dB 増幅され、「な」が「ざ」になった。
2. **破裂音の気息**は 6kHz まで通していた。破裂直後の息は声道がまだ
   開いておらず 2kHz 以下にこもる音なのに、平らなノイズが 75ms 鳴り、
   「か」が「ざ」になった。

修正は 2 つ。

- 正規化を**音素ごと**にする。各音素の区間でノイズと有声のピークを測り、
  その音素の中だけで -12dB に合わせる。無声の子音 (/h/ /s/) は区間に
  有声出力が無いので、語全体の有声ピークを基準にする (これを 0 に
  していたため /h/ がまるごと消えるバグを一度作り込んだ)。
  休止 (句読点) には混ぜない (直前の母音の減衰が入り、ゲインが跳ねる)。
- ノイズ経路の帯域上限を音素ごとに切り替える。破裂音の気息は
  `radNLp` を **1.2kHz** に、摩擦音は **6kHz** のまま。

| 音 | 4-8kHz のエネルギー比（最大） | |
|---|---|---|
| | 修正前 | 修正後 |
| な | −6.8 dB | **−19.3 dB** |
| ま | −7.1 dB | **−19.4 dB** |
| か | −6.3 dB | **−17.5 dB** |
| ぱ | −6.4 dB | **−17.7 dB** |
| が | −8.0 dB | **−20.9 dB** |
| や / ら / わ | −16 / −16 / −16 dB | **−34 / −33 / −35 dB** |
| **さ / し / は** | −1.0 / −2.7 / −5.9 dB | **据え置き**（摩擦音はこの帯域が音） |

摩擦音の重心は さ **4775Hz**、し **4263Hz** で修正前と同一。
「さ」が「は」に、あるいは「し」が「す」に変わらないことを
`test_fricative_stays_bright` が重心 3000Hz 以上で見張る。

## 声質の目標（ボイス要望の参照音声から）

`ボイス要望/` に置かれた参考音声 2 本を分析して、目標値を次のように決めた。

| 指標 | 参考音声 | 以前のエンジン | 現在 |
|---|---|---|---|
| F0（中央値） | 280 / 302Hz | 227Hz | 271Hz |
| スペクトル重心 | 640 / 828Hz | 1132Hz | 794Hz |
| 3kHz 以上の相対レベル | −56〜−60dB | −47dB | −55dB 前後 |

- **ピッチが低すぎた。** 参考は 280〜300Hz。`yukkuri` を 235 → 280Hz にし、
  ほかのプリセットも比率を保って上げた（まりさ 245Hz など）。
- **明るすぎた。** 原因は 3kHz 以上のシェルフ `kShelf`（3.2 倍）。これを 1.4 倍に下げた。
  2.5kHz 以上が 10〜20dB 下がり、重心が 640〜830Hz の帯に入る。
  `kShelf` は有声経路にしか掛からないので、摩擦音の明るさ（さ/す 4730Hz、
  し 4051Hz、は 3375Hz）は据え置き。子音の識別には影響しない。
- フォルマント倍率（1.09）は**変えていない**。下げると /い/ の F1 が
  F0 の谷に落ちて母音が潰れる（実測: 倍率 1.00 で い の F1 が 533Hz になり不合格）。

## 鼻音の閉鎖

「おつかれさま」が「おつかれさあ」に聞こえる問題があった。
原因は **/m/ に閉鎖区間が無かった**こと。鼻音は `closure_ms()` が 0 を返していたため、
「ま」が単なる母音として鳴り、末尾の「あ」と区別できなかった。

- `closure_ms()` が鼻音（/m/ /n/ /ŋ/ /ɲ/）に 45ms を返すようにした
- 閉鎖区間では**声帯を止めない**（止めると /m/ ではなく促音「ッ」になる）。
  音量だけ 0.30 倍まで落として「口を閉じた鼻音」にする
- 実測: 「おつかれさま」の末尾に約 60ms の低レベル区間が入り、
  「さ」→閉鎖→「ま」の 3 拍として聞き取れるようになった


## 音素記号列の入力

かなだけでなく、**発音そのもの**を記号列で指定できる。ローマ字・かな・記号を
混在させてよい。日本語の異音規則は自動で当たる。

```
ゆっくりしていってね          <- かな (従来どおり)
yuQkuri shite iQte ne        <- ローマ字
ゆQkuri shite iQte ne        <- 混在
```

| 記号 | 意味 | 例 |
|---|---|---|
| `a i u e o` | 母音 | `a` = あ |
| `ka ki ku ke ko` ... | 子音 + 母音 | `kya` は拗音で 1 モーラ |
| `N` | 撥音 (ん) | `saNpo` |
| `Q` | 促音 (っ)。次の子音の閉鎖を伸ばす | `yuQkuri` |
| `:` `ー` | 長音。直前の母音を 1 モーラ伸ばす | `a:` |
| `,` `.` `-` `、` `。` | 休止 | `a, b` |
| `'` | アクセント核。直前のモーラの直後に置く | `ha'shi` (箸) / `hashi'` (橋) |
| `` ` `` | 下降の指定 (核を下げる) | `ka`ku` |
| `/` `;` `+` | アクセント句の境界。**ポーズは入らない** | `a/i` |
| `,` `、` | 短い休止 | `a, b` |
| `.` `。` | 長い休止 | `a. b` |

`shi chi tsu ji` のような日本語の特殊な組み合わせも解釈する。
拗音 (`kya` `sha` `cha` など) は「口蓋化した子音 + 母音」の 1 モーラとして扱い、
`k` + `y` + `a` の 3 音素にはしない (以前そうなっていて間延びしていた)。

### 自動変換 (かな -> 記号)

`yk_kana_to_symbols()` で、かな入力を実際に発音する音素記号列に変換できる。
アプリの読み表示の下にこれが出るので、何が起きているか目で確認できる。

```
ゆっくりしていってね  -> y u Q k u r i sh U t e ʔ i Q t e n e
さんぽ                -> s a m p o
まんが                -> m a ng g a
きって                -> k U Q t e
```

`U` は無声化した母音、`ʔ` は声門破裂、`Q` は促音。

### 日本語の異音規則 (かな入力にも自動で適用)

かな入力・記号入力のどちらでも、`yk_apply_allophones()` が次を当てる。
以前はどれも入っておらず、これが「日本語として不自然」の主因だった。

| 規則 | 内容 | 例 |
|---|---|---|
| ん の同化 | 後続子音の調音点に合わせる | さんぽ → `s a m p o` (両唇鼻音)、まんが → `m a ng g a` (軟口蓋鼻音) |
| 母音の無声化 | 無声子音に挟まれた い/う を息だけにする | きって → `k U Q t e`、すき → `s U k i` |
| ら行の弾き音 | 語中の ら行を短い 1 タップにする | 「あら」の ら は語頭の 55ms → 30ms |
| 語末の弱化 | 文末の す をわずかに弱める | です・ます |
| ガ行鼻濁音 | 語頭は破裂音 [g]、語中・語尾は鼻音 [ŋ] | がっこう → `g a...` / かぎ → `k a ng i` / ありがとう → `... ng a ...` |

**単独の「す」「し」は無声化しない。** 単語を 1 つだけ発音するときは母音が残る
(無声化は「後ろに無声子音が続く」ときだけ)。これを間違えると、単独の「す」が
息だけになって摩擦音のテストが落ちる。


## テスト
`tools/test_engine.c` が CI で実行される。

- プリセットの妥当性（F0 範囲・合成成功）
- かな列の読み（促音・長音の保持）
- 母音の F1/F2 が設計値どおりか（F0 の高調波をたどって測定）
- クリップしていないか、母音間の音量差が 3 倍以内か
- 句点で間が入るか
- アクセントがピッチで表されているか（平板は上がり、頭高は下がり、尾高は助詞で下がる）
- アクセントが音量 (`amp`) を壊していないか
- `/` が声門破裂や休止になっていないか
- ガ行鼻濁音（語頭 g / 語中 ŋ）
- 子音・閉鎖・気息に広帯域ノイズが乗っていないか（8kHz 以上の比 < −16dB）
- 音素テーブルの行数が `YK_P_COUNT` と一致しているか（記号が空の音素が無いか）
- 母音の連続に声門破裂・破擦音・子音が挟まっていないか
- 母音の連続のあいだが無音で分断されていないか（最小 2ms RMS > 0.001、8kHz 以上の比 < −40dB）
- 音素記号 `?` が声門破裂として解釈されるか
- 鼻音・破裂音の子音区間に 4-8kHz の広帯域ノイズが乗っていないか（< −13dB）
- 摩擦音（さ・し）の重心が 3kHz 以上か（上の修正で暗くしていないか）
- 休止にノイズを混ぜて文末の母音を覆っていないか

音響分析は `tools/formant.py`（LPC）と `tools/spectrum.py`（1/3 oct）で手動確認できる。
