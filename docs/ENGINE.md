# エンジン設計メモ

## 目標
「ゆっくり声」の特徴を、パラメータとして明示的に再現すること。

ゆっくり声の印象は主に次の 3 つで決まる。

1. **高い F0 と平坦なピッチ** — 抑揚を小さく、文末だけ軽く下げる
2. **フォルマントの上方シフト** — 声道長が短い話者に相当（倍率 1.05〜1.16）
3. **遅い話速と長い母音** — 0.55〜0.9 倍速、母音 95〜115ms

これらは `YkPreset` のフィールドとして外部化してあり、
キャラクタはプリセットの組み合わせで表現する。

## 音源モデル
      声帯パルス ──┐
                    ├─→ 5 段共振器 (F1..F5) ─→ 放射特性 ─→ 自動音量 ─→ 出力
      帯域ノイズ ──┘

- **声帯パルス**: ノコギリ波 + 3 次歪み（`saw - 0.4 saw^3`）を 1.4kHz でローパス。
  F0 には 5.4Hz のビブラートと微小ジッタを重ねる。
- **帯域ノイズ**: 摩擦音の帯域（`/s/` 6.2kHz、`/sh/` 3.4kHz、`/h/` 1.6kHz）を
  2 次共振器で作る。破裂音は閉鎖（無音）＋バースト。
- **共振器**: `H(z) = a / (1 - b z^-1 - c z^-2)`、`a = 1 - b - c` で DC ゲイン 1。
  帯域幅は F1 で最も狭く、高次ほど広い。F1/F2 は Q の上限を設けて
  低い F0 での発振を防ぐ。
- **放射特性**: 唇の放射は +6dB/oct。サンプル差分で近似するが、
  共振器のピーク付近で暴れないよう係数 0.7 の弱い傾斜にしている。
- **音量**: 音素ごとの `gain`（母音の共振器減衰差を吸収）と、
  短時間 RMS の 75 パーセンタイルを基準にした全体正規化の 2 段構え。

## 音素表
`core/src/phones.c` の `YkPhoneInfo` がすべて。

| フィールド | 意味 |
|---|---|
| `voiced` / `formant[5]` / `bw` | 有声源とその共鳴特性 |
| `noise` / `noiseHp` / `noiseF` / `noiseBw` | 摩擦・破裂ノイズ |
| `amp` / `gain` | 振幅と共振器減衰の補正 |
| `dur` | 既定長 [ms] |

母音は `core/src/internal.h` の `YK_VOWEL_F`（成人男性の平均値）を使い、
`formantScale` を掛けて声質を作る。

## 韻律
`plan.c` の後半。現状は簡易版:

- モーラごとに 2 モーラ周期のアクセント（強 / 弱）
- 文全体で 6% の緩やかな下降
- 文末 1〜3 モーラで 4 半音の下降
- `intonation` プリセット値でこの抑揚の深さを調整

将来はアクセント辞書（例: 東京式アクセント）に差し替える想定で、
`YkPhoneme.f0` を埋める部分だけを交換すればよい構造にしてある。

## テスト
`tools/test_engine.c` が CI で実行される。

- プリセットの妥当性（F0 範囲・合成成功）
- かな列の読み（促音・長音の保持）
- 母音の F1/F2 が設計値どおりか（F0 の高調波をたどって測定）
- クリップしていないか、母音間の音量差が 3 倍以内か
- 句点で間が入るか

音響分析は `tools/formant.py`（LPC）と `tools/spectrum.py`（1/3 oct）で手動確認できる。
